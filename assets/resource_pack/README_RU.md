# FrizProject items atlas

Этот Bedrock resource pack нацелен на клиент 1.21.114 (`min_engine_version`). Он содержит manifest и атлас PNG-иконок. Установите `FrizProject-Items-1.4.0.mcpack` в клиенте. В плагине используются переименованные vanilla-предметы; собственные runtime item definitions и привязка атласа ещё не реализованы, поэтому иконки пока не появятся на соответствующих предметах сервера.
