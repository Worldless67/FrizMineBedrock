# Целевая версия Bedrock

Проект собирается для клиента Minecraft Bedrock 1.21.114.

- Maven-свойства `bedrock.target.version` и `bedrock.target.protocol` задают `1.21.114` и `844`.
- Итоговый JAR получает суффикс `bedrock-1.21.114`.
- Resource Pack требует engine version `[1, 21, 114]`.
- Для Nukkit-MOT используется overlay `assets/server-config/nukkit-mot-1.21.114.yml`: минимум и максимум multiversion равны `844`.
- В протокольной таблице Nukkit-MOT идентификатор 844 называется `1.21.111`; версия ядра `1.26.60-R1` — отдельная версия серверного API и не подменяет целевой клиент.

Тестовый сервер успешно прочитал overlay, запустил плагин и выполнил команду Creator при диапазоне `844–844`. В среде нет Bedrock-клиента 1.21.114, поэтому реальное сетевое подключение этой версии не проверено. Установка overlay ограничивает именно протокольный номер; если клиент 1.21.114 использует 844, сервер его принимает.

Ядро Nukkit-MOT 1.26.60-R1 требует Java 21+. Сам плагин компилируется с `--release 17`.
